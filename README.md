### Hacker Card ###

#About 
#### What is a Hacker Card? ####
Hacker Card is a PCB (Printed Circuit Boards) business card with a twist - it can light up using NFC chip and custom designs.
<video src="movie.mov" controls width="200px"> </video>

#### Features:
- Programmable NFC
- LEDs
